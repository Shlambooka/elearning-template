Negative feedback: keeping things steady

Module 1 of 4 25%

Negative feedback is a loop where the system responds to a change by pushing in the opposite direction. The result is stability.

Everyday example: a thermostat

You set a room to 21 °C. The room cools below that, so the heater turns on. Once it warms up past 21 °C, the heater switches off. The system is constantly nudging the temperature back toward the target.

Knowledge check

Which of these is an example of a negative feedback loop?

Key idea

Negative feedback doesn't mean "bad". It means the response opposes the change. The system is trying to return to balance.
